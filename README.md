# OrderRelay – Portfolio Tool

Personal application for quantitative trading research, portfolio and risk management across
the owner's own trading accounts, with integration of the cTrader Open API.

OrderRelay distributes the owner's own trading signals across the owner's own accounts and
calculates position sizes and risk. cTrader accounts are connected only after explicit
authorisation through the official cTrader OAuth process. Orders are placed only when the owner
has granted trading permission and enabled execution for that account. OrderRelay is not a
broker and gives no investment advice.
